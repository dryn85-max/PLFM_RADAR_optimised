## Fixed byte layouts (all little-endian)

- **Recording request** (PC -> ESP32, 12 B): `"LDRQ"`, `version u8 = 1`, `reserved u8[3] = 0`,
  `from_seq u32`.
- **Batch** (ESP32 -> PC): header 16 B = `"LDRB"`, `version u8 = 1`, `flags u8` (bit0 `GAP`: the
  requested start was older than the oldest stored frame), `reserved u16 = 0`, `first_seq u32`,
  `count u16`, `reserved u16 = 0`; then `count` records `{seq u32, esp_time_us u64, len u16,
  raw[len]}`. A batch with `count = 0` is sent every second while idle (keep-alive).
- **File** (`.ldrec`): header 20 B = `"LDREC1\0\0"`, `version u16 = 1`, `reserved u16 = 0`,
  `created_unix_ns u64`; then records starting with `type u8`: `0` frame `{seq u32,
  esp_time_us u64, pc_time_ns u64, len u16, raw[len]}`, `1` gap `{from_seq u32, to_seq u32,
  pc_time_ns u64}` (missing range `[from_seq, to_seq)`).
- Shared test vectors: `esp32/tests/vectors/*.bin` + `*.json` (expected decode), used by the C
  tests and `host/test_ld2410_rec.py`.

## Task 2: hardware-independent core + host tests (spec R2, R3, R5)

- [ ] `esp32/components/core/` (plain C11, no ESP-IDF headers): `ld2410_parser.[ch]` (incremental
  byte-stream framer for data and ACK frames, fixed max frame size, resync on garbage),
  `ld2410_frame.[ch]` (decode data frame -> struct, engineering fields optional),
  `ld2410_cmd.[ch]` (encode command frames, decode ACK), `ringbuf.[ch]` (variable-length records
  with seq/time in a caller-provided memory block; push, oldest/newest seq, read from seq with
  GAP indication; not thread-safe by itself — caller locks), `rec_proto.[ch]` (request parse,
  batch encode into a caller buffer with size limit), `snapshot_json.[ch]` (fixed-size buffer,
  snprintf-based, never truncates silently: returns error). `CMakeLists.txt` registering the
  component for ESP-IDF.
- [ ] `esp32/tests/`: Makefile (`make test`, gcc, `-std=c11 -Wall -Wextra -Werror
  -fsanitize=address,undefined`), test files per module, shared vectors under `vectors/`.
  Adversarial cases: frames split at every byte boundary, two frames in one chunk, garbage and
  false headers inside payload, length > max, wrong footer, truncated engineering payload,
  ring buffer wrap/overwrite/oldest-evicted request, batch that does not fit the output buffer,
  sequence wrap at 2^32.
- [ ] Commit.
