## Fixed layouts (all little-endian)

- **Request** (12 B): `"LDRQ"`, `version u8 = 3`, `reserved u8[3] = 0`, `from_seq u32`. Server
  closes on any other version.
- **Batch** header (20 B): unchanged layout, `version u8 = 3`. Records:
  `{seq u32, esp_time_us u64, type u8, len u16, payload[len]}` (15 B header).
- **Record types / payloads:**
  - `0 ld2410_frame`: raw LD2410C frame bytes (unchanged content).
  - `1 gps_fix` (32 B): `utc_unix_ms i64` (0 if time/date invalid), `lat_e7 i32`, `lon_e7 i32`,
    `alt_cm i32`, `speed_cmps u16` (saturating), `course_cdeg u16`, `hdop_x100 u16`,
    `sats u8`, `fix_quality u8` (GGA value), `flags u8` (bit0 time valid, bit1 date valid,
    bit2 position valid, bit3 altitude valid), `reserved u8[3] = 0`.
  - `2 imu` (18 B; the first draft said 19, the fields sum to 18): `acc_mg i16[3]`, `gyr_ddps i16[3]` (0.1 °/s), `pitch_cdeg i16`,
    `roll_cdeg i16`, `n_samples u8`, `status u8` (bit0 data valid).
  - `3 time_sync` (9 B): `utc_unix_us i64`, `source u8` (1 GPS, 2 SNTP).
- **File** `.ldrec` v3: header unchanged layout, `version u16 = 3`; record `type u8` values:
  `0` frame, `1` gap, `2` reboot (layouts unchanged), `3` gps_fix, `4` imu, `5` time_sync, each
  `{seq u32, esp_time_us u64, pc_time_ns u64, len u16, payload[len]}`, and `6` unknown
  `{seq u32, esp_time_us u64, pc_time_ns u64, wire_type u8, len u16, payload[len]}` (types 0-6).
  The recorder still reads v2 files.
- Ring buffer: store the record type with each record (extend `ringbuf` record header by one
  byte or prefix; wire format above is what matters). Exact payload sizes above are normative;
  if a field needs to change, change spec, plan, C, Python and vectors together and report it.

## Task 1: protocol v3 core + host recorder

- [ ] C: `ringbuf` typed records; `rec_proto` v3 (request/batch/record encode/parse, version
  check); payload encode/decode helpers for `gps_fix`, `imu`, `time_sync` in core.
- [ ] Vectors: regenerate/extend (`gen_vectors.py`), one per record type, a mixed batch, keep the
  two real LD2410C frames (now wrapped as type 0 records where needed).
- [ ] Python: v3 reader/writer, v2 file compatibility, UTC conversion (GPS sync within +-2 s
  first, else nearest preceding time_sync of any source, fallback following), `export-csv` extra columns + `--gps`/`--imu`, `info` stats;
  fake-server tests for mixed records, resume and reboot with v3.
- [ ] Firmware glue only as needed to keep the build green (the LD2410C task now pushes type 0).

## Task 2: NMEA parser + GPS task

- [ ] Core `nmea.[ch]`: line assembler (bounded, CR/LF), checksum, RMC/GGA for GP/GN, epoch
  combining into a `gps_fix` struct; tests: valid sentences, bad checksum, truncated lines, empty
  fields without fix, midnight/date rollover, S/W hemispheres, max-length line, garbage bytes.
- [ ] `main/gps_task.[ch]`: UART2 9600 on GPIO4/5, feed parser, push `gps_fix` each epoch and
  `time_sync` (source GPS) on valid RMC time+date; latest fix for the live page; absent/silent
  detection (> 3 s).

## Task 3: BMI160 + tilt

- [ ] Core `tilt.[ch]`: complementary filter, averaging into 100 ms records; tests: known static
  angles, ±90°, ±180° wrap, gyro-only step, averaging counts.
- [ ] `main/imu_task.[ch]`: I²C master (ESP-IDF v5.5 `driver/i2c_master.h`) on GPIO8/9, 400 kHz,
  probe 0x68/0x69, chip-ID check, configure acc ±4 g / gyro ±500 °/s / ODR 100 Hz (register values
  from the datasheet; VERIFY if not in `hardware/datasheets/`), read at ~100 Hz, push `imu`
  records every 100 ms; error counting and retry with backoff; never blocks the LD2410C task.

## Task 4: SNTP time
